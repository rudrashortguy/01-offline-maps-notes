# GeoNotes PWA

Offline-first map note-taking app with Geolocation and IndexedDB persistence.

### Features
- Leaflet Map integration
- IndexedDB offline storage
- Geo-tagged markers
- Workbox caching

### Tech Stack
- **Vite** & **TypeScript**
- **Workbox / Vite PWA Plugin** for offline capabilities
- **IndexedDB & LocalStorage** for persistent state

### Getting Started
```bash
npm install
npm run dev
```
